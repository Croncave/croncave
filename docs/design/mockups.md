# UI mockups

The mockups live on a design canvas on claude.ai: https://claude.ai/artifact/UiRePeq7vzwoqQfAosvUG5 (private to the account owner). They were made during planning and are directional, not final. "Nightshift" on them is the old working name.

| Screen | What it shows |
| --- | --- |
| Home: what needs you | One composer ("What do you want to get done?") with quick-start chips and "Set up manually"; cards for items needing a decision; "Running" and "Done recently"; a spend meter |
| Workspace: Stock Watcher | A dashboard built from standard components (stats, watchlist table, chart with threshold, plain-language timeline), with chat docked on the right. Requests become "proposed change" cards with Approve and "Edit in form" |
| View component library | The fixed set of 12 components, grouped as Show, Collect and Act. AI composes views from these and never invents new UI |
| Founder: change review | Session summary, per-change keep/leave-out checkboxes linked to user feedback, before/after screenshots, proof chips (tests, browser check), then the diff, with a box to request a tweak |
| Designer: prototype workspace | A clickable prototype in a device frame, a screen list, "Notes for AI" pinned on the prototype with statuses, versions, Present, and share/export options |

Recurring pattern across screens: **AI proposes, people approve** (plan cards, change review checkboxes, notes with statuses).
